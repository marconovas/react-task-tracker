# React Task Tracker

A task management application built with React. It allows users to create, edit, complete, and delete tasks, with persistent storage using localStorage.

## 🚀 Features

* Create new tasks
* Mark tasks as completed
* Edit tasks inline
* Delete tasks
* Persistent data with localStorage
* Component-based architecture

## 🛠️ Technologies

* React
* JavaScript (ES6+)
* HTML & CSS

## 📁 Project Structure

src/
components/
TaskInput.jsx
TaskList.jsx
TaskItem.jsx
App.jsx
main.jsx

## ⚙️ Installation

```bash
git clone https://github.com/your-username/react-task-tracker.git
cd react-task-tracker
npm install
npm run dev
```
